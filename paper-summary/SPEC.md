# Paper Summary 스킬 명세

## 목적

전 분야 연구논문을 연구자 관점에서 검증 가능하게 요약한다. PDF를 우선 지원하며, 실증 연구·이론 논문·리뷰·메타분석을 포함한다.

## 대상과 기본값

- **독자:** 해당 분야 연구자
- **입력:** 사용자가 제공한 논문 PDF 또는 본문·발췌문
- **출력:** 대화 내 Markdown 브리핑
- **기본 언어:** 한국어. 핵심 전문 용어와 제목은 필요하면 원어를 병기한다.
- **기본 분량:** 중간 길이. 사용자가 지정한 언어·독자·길이·형식이 있으면 요청을 따른다.
- **외부 검색:** 기본으로 하지 않는다. 요청되거나 후속 질문에 필요한 경우에만 보완 자료로 사용하고, 논문 원문 근거와 구분한다.

## 필수 요약 항목

모든 요약은 아래 여섯 항목을 이 순서대로 포함한다. 논문 유형에 맞게 내용을 조정하고, 자료가 부족하거나 해당되지 않는 항목도 생략하지 말고 확인 범위와 한계를 밝힌다.

1. **연구 목적·연구 질문·핵심 요지** — 연구 동기, 명시된 질문 또는 목적, 중심 주장과 요점을 정리한다. 질문이 직접 제시되지 않았다면 목적에 대한 해석임을 표시한다.
2. **이론적 배경 및 Literature Review** — 논문이 활용하는 이론, 선행 결과, 연구 공백을 정리한다. 이론 논문은 개념적 계보와 전제를, 리뷰·메타분석은 문헌 범위와 구성 방식을 다룬다.
3. **방법·자료** — 연구 설계, 자료·코퍼스, 표본·대상, 측정·분석 방법과 주요 절차를 설명한다. 이론 논문이나 리뷰처럼 경험 자료가 없는 유형에는 해당 유형의 접근법을 기술한다.
4. **주요 결과** — 연구 질문에 답하는 주요 발견·명제·종합 결과를 보고하고, 중요한 조건과 불확실성을 보존한다. 상관관계 자료로 인과를 단정하거나 보고되지 않은 통계적 의미를 덧붙이지 않는다.
5. **고유 기여 (Unique contribution)** — 관련 문헌 대비 새로운 증거·이론·방법·종합·관점을 설명한다. 저자의 기여 주장과 요약자의 독자성 평가를 구분한다.
6. **핵심 비판점 (Critical points)** — 논문의 주장과 근거에 기반한 주요 한계·열린 질문을 평가한다. 저자가 인정한 한계와 요약자의 비판을 구분하고, 설계·자료·추론·범위·보고상의 구체적 문제와 그 영향을 설명한다.

## 근거·인용·불확실성

- 핵심 주장이나 해석이 중요하거나 모호할 때 짧은 직접 인용을 선택적으로 붙이고, 페이지 위치를 함께 표시한다. 인용은 설명을 대신하지 않으며 긴 구절을 옮기지 않는다.
- 페이지는 **논문에 인쇄된 쪽수**를 우선한다. 확인할 수 없으면 **PDF 쪽수**라고 명시한다. 둘 다 확인 가능하고 유용하면 각각 구분해 쓴다.
- PDF 뷰어 쪽수를 논문 인쇄 쪽수인 것처럼 표시하지 않는다. 제공된 텍스트에 페이지 정보가 없으면 쪽수를 만들어내지 않는다.
- 논문에 명시된 사실과 요약자의 해석을 구별한다. 일부 자료만 제공된 경우 확인한 범위를 명시하고 그 자료 안에서만 결론을 낸다.
- 필요한 근거를 찾을 수 없거나 논문 유형상 해당하지 않는 내용은 추측하지 않는다. 확인 불가 또는 비적용 사유를 해당 항목에 짧게 기록한다.
- 비판은 실제 논문의 주장과 근거를 대상으로 한다. 비판할 근거가 부족하면 그 제약을 알리고 억지로 비판점을 만들지 않는다.

## 수용 기준

- 모든 결과에 여섯 항목이 정해진 순서로 표시된다.
- 실증·이론·리뷰·메타분석 유형에 맞게 방법과 문헌 검토를 조정한다.
- 핵심 주장의 인용은 짧고 원문 위치를 확인할 수 있으며, 인쇄 쪽수와 PDF 쪽수를 혼동하지 않는다.
- 근거가 부족하거나 자료가 부분적일 때 확인 범위·불확실성·한계를 밝히고 내용을 임의로 채우지 않는다.
- 저자 주장, 논문에 보고된 결과, 요약자의 해석과 비판이 서로 구별된다.
